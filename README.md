# 🏦 Banking Management System

A console-based banking application built with Python using OOP concepts.

## Features
- Deposit Money
- Withdraw Money  
- Check Balance
- View Transaction History

## Technologies Used
- Python
- OOP (Classes, Encapsulation)
- Loops & Conditional Statements
- Functions

## Project Structure
banking_management_system/
├── main.py
├── bank_account.py
└── utils.py

## How to Run
python main.py
